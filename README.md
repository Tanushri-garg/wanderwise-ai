# WanderWise AI

WanderWise AI is an AI-powered travel planning web application that helps users create personalized travel plans based on their destination, budget, trip duration, and number of travelers.

## Features

- AI-powered travel planning
- Personalized daily itinerary
- Hotel suggestions with estimated prices
- Weather information
- Transportation recommendations
- Food and activity suggestions
- Complete budget breakdown
- Budget allocation and remaining budget
- Money-saving tips
- AI travel chat
- Responsive and modern UI

## How It Works

1. Enter your destination and trip details.
2. Set your total travel budget.
3. Enter the number of travelers and trip duration.
4. Ask WanderWise AI to plan your trip.
5. Get a personalized itinerary with hotels, weather, activities, transportation, food, and budget details.

## Tech Stack

- React
- Vite
- JavaScript
- Gemini AI
- HTML & CSS
- Vercel

## AI Integration

WanderWise AI uses Google's Gemini API to generate personalized travel recommendations and itineraries.

The Gemini API key is stored securely as an environment variable and is not exposed in the frontend code.

## Deployment

The application is deployed using Vercel.
